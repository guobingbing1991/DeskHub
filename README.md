# 桌面管理器 DeskHub

macOS 桌面工作台：把你手动添加的应用的真实窗口，停靠到屏幕右侧的工作区里。点左栏图标切换，右键图标还原。
纯原生、零第三方依赖；不收集任何数据。

## 下载

**[下载最新版（.dmg）](https://github.com/guobingbing1991/DeskHub/releases/latest)**

要求 macOS 14 或更高；Apple 芯片与 Intel 芯片通用。

## 安装

1. 打开下载的 .dmg，把「桌面管理器」拖进「应用程序」文件夹。
2. 第一次打开时系统会弹出「未打开“桌面管理器.app” — Apple 无法验证“桌面管理器.app”是否包含可能危害
   Mac 安全或泄漏隐私的恶意软件」。这是因为应用没有使用苹果付费开发者账号签名，并不是应用有问题。
   请点「完成」，打开「系统设置 › 隐私与安全性」，拉到底部，点「仍要打开」，然后再次双击应用。
   **只需要做这一次**，之后（包括应用内更新）都不会再拦。
3. 按应用里的引导授权两项权限：「屏幕录制」（识别窗口）和「辅助功能」（移动窗口）。

## 更新

有新版本时，左侧栏底部会出现一个蓝色的小更新图标，点它查看更新内容，点「下载并更新」即可自动完成，
已授过的权限会保留。也可以右键点程序坞里的「桌面管理器」图标，选「检查更新…」手动检查；不想要自动检查，
在同一个菜单里取消勾选即可。

## 隐私

应用只在「检查更新」时访问 GitHub（查询版本、下载安装包），请求不携带任何个人信息，也没有遥测。
其余功能完全在本地运行。
